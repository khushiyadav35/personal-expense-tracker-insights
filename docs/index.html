B.Tech Viva Defense & Interview Cheat Sheet

Q1: Why use TF-IDF + Calibrated Linear Model instead of a large LLM / BERT?

In mobile fintech, transactions require real-time categorization on low-power devices (< 5ms latency). Large language models introduce high memory overhead and inference delays. TF-IDF unigram+bigram representations combined with Calibrated Logistic Regression achieve 98.48% accuracy while running in microseconds with zero cloud latency.

Q2: How does the system handle privacy and PII in Bank SMS?

Before text reaches any analysis layer, the Anonymizer pipeline strips phone numbers via regex [6-9]\d{9}, masks account numbers to XX****1234, and scrubs VPA handles (user@bank). No raw financial credentials or PII ever leave the client boundary.

Q3: What mathematics govern the Spending Anomaly Detector?

We use category-specific Interquartile Range ($IQR = Q_3 - Q_1$) and Robust Z-Scores ($Z = (x - \mu)/\sigma$). A transaction is flagged if $x > Q_3 + 1.5 \times IQR$ or $Z > 2.2$. This isolates authentic anomalies (e.g. Diwali shopping or medical emergencies) without triggering false alarms on regular variable groceries.

Q4: How does Holt-Winters Double Exponential Smoothing forecast next month?

It decomposes the series into level ($\ell_t$) and trend ($b_t$):
$\ell_t = \alpha y_t + (1-\alpha)(\ell_{t-1} + b_{t-1})$
$b_t = \beta(\ell_t - \ell_{t-1}) + (1-\beta)b_{t-1}$
$y_{t+1} = \ell_t + b_t$. We tune $\alpha=0.4$ and $\beta=0.2$ to balance recent velocity with long-term stability.
